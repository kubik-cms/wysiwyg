# @kubik-cms/wysiwyg

Editor.js widgets and Stimulus controllers for Kubik CMS Active Admin.

**Full documentation:** [docs/WYSIWYG.md](../docs/WYSIWYG.md)

Quick start:

```bash
cd package && yarn install && yarn build
```

Host apps pin `dist/wysiwyg.es.js` in importmap and register `KubikWidgetController`, `KubikRepeaterController`, and related controllers from the package export.
